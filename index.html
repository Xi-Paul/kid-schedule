시작하는 중
일정 시간에 알림을 받으려면 켜 주세요.
    설정 탭에서 역할을 부모로 바꾸면 일정을 편집할 수 있습니다.

    일정 추가

    제한시간을 비우면 종료−시작 시간을 제한시간으로 씁니다. 끝 시간도 없으면 60분입니다.

    매주 반복 일정

    요일별로 묶어서 보여줍니다. 각 요일의 + 추가를 누르면 그 요일이 미리 선택된 채로 입력 칸으로 올라갑니다.

    하루만 있는 일정

    지난 날짜는 자동으로 숨깁니다.

      기본값

      체크 허용 시간창 밖에서는 아이가 완료를 누를 수 없습니다. 몰아서 체크하는 걸 막습니다. 이 값은 이 기기에만 저장되므로, 모두에게 적용하려면 저장소의 config.json 을 고치세요.

      저장소에 반영

      위에서 고친 내용은 아직 이 기기에만 있습니다. 저장을 눌러야 schedule.json 으로 커밋됩니다.

      저장소 연결

      토큰은 이 기기의 브라우저에만 저장되고 저장소에는 올라가지 않습니다. GitHub → Settings → Developer settings → Fine-grained tokens 에서 이 저장소만 선택하고 Repository permissions → Contents 를 Read and write 로 주세요.

      역할이 실제로 막아주는 것

      역할은 이 앱 화면에서만 구분됩니다. GitHub 토큰은 파일 경로별로 권한을 나눌 수 없고, 최소 단위가 저장소입니다. 그래서 아이 기기 토큰이 새면 같은 저장소의 일정도 바뀔 수 있습니다. 진짜로 분리하려면 기록 전용 저장소를 따로 만들고, 아이 토큰은 그 저장소에만 권한을 주세요. 위의 기록 저장소 칸이 그 용도입니다.
